# Sitio web · Cumbre de Transformación Empresarial Amazonas 2026

Sitio estático (HTML + CSS + JS, sin dependencias). Se publica tal cual en Vercel, Netlify o cualquier hosting.

- `index.html` — página del evento.
- `demo.html` — demo en vivo de tienda virtual de KubIA Soluciones (todo queda en el navegador del usuario, máx. 10 productos).
- `js/datos.js` — **aquí se edita todo el contenido**: ponentes (biografía, experiencia, proyectos, material que entregan, redes), programa, patrocinadores (con enlace opcional) y fecha de la cuenta regresiva. Los campos vacíos no se muestran.

Para verlo en local: `python3 -m http.server` dentro de esta carpeta y abrir http://localhost:8000
